# INCUBE — المنيو الإلكتروني

منيو إلكتروني لشاشة آيباد أو تابلت أفقية (مصمم على مقاس 1920×1200، ويتغير حجمه تلقائياً ليملأ أي شاشة).
الجهة اليمنى تعرض المنيو، والجهة اليسرى لوحة إعلانية لصور المنتجات والإعلانات.

موقع ثابت (HTML/CSS/JS) بدون قاعدة بيانات وبدون خادم: كل التعديلات تُحفظ في متصفح الجهاز.

## الصفحات

| الصفحة | الوصف |
|---|---|
| `index.html` | شاشة المنيو للزبائن |
| `admin.html` | لوحة التحكم (الرمز الافتراضي: `1234`) |

للوصول إلى لوحة التحكم من شاشة المنيو: اضغط مطوّلاً **3 ثوانٍ** على كلمة INCUBE أو على عنوان "القائمة".

## لوحة التحكم

1. **الأصناف والأسعار**: تعديل الأسماء والسعرات والأسعار، وإظهار أو إخفاء أي صنف أو قسم، وتحديد المشروب المميز ★، وترتيب الأصناف، وإضافة صورة لكل صنف، وإضافة الأصناف والأقسام أو حذفها.
2. **اللوحة الإعلانية**: تشغيلها أو إطفاؤها (عند الإطفاء يأخذ المنيو كامل الشاشة)، وتعديل نص الشعار، ومدة عرض كل إعلان، وإظهار بطاقة السعر.
3. **الإعلانات**: إضافة إعلانات بالصور أو إعلانات نصية، وتشغيل أو إيقاف كل إعلان، وترتيبها، وربط الصورة بصنف لإظهار اسمه وسعره.
4. **النصوص والإعدادات**: نصوص أسفل المنيو بالعربي والإنجليزي، والعملة، ولغة البداية، والوضع التلقائي، وتغيير رمز الدخول.
5. **النسخ الاحتياطي**: تحميل نسخة احتياطية (ملف JSON يشمل الصور المرفوعة)، ورفع نسخة، واستعادة البيانات الافتراضية.

### مهم عن الحفظ المحلي
- التعديلات محفوظة في **متصفح الجهاز نفسه** فقط. عدّل من لوحة التحكم على الآيباد الذي يعرض المنيو، أو عدّل على جهاز آخر ثم انقل التعديلات بتحميل النسخة الاحتياطية ورفعها على الآيباد.
- إذا كانت شاشة المنيو مفتوحة في تبويب آخر على نفس الجهاز، تظهر التعديلات فيها فوراً.
- مسح بيانات سفاري أو استخدام التصفح الخاص يحذف التعديلات، لذا احتفظ دائماً بنسخة احتياطية.
- مساحة التخزين في المتصفح نحو 5 ميجابايت. الصور المرفوعة تُصغَّر تلقائياً قبل حفظها.
- رمز الدخول يمنع الزبائن من فتح لوحة التحكم بالخطأ فقط، وليس حماية أمنية.

## النشر على GitHub Pages

1. من إعدادات المستودع: **Settings → Pages**.
2. في **Source** اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة يصبح الموقع متاحاً على الرابط الذي تعرضه الصفحة.

## التشغيل على الآيباد

1. افتح رابط الموقع في سفاري.
2. من زر المشاركة اختر **إضافة إلى الشاشة الرئيسية** ليفتح المنيو بملء الشاشة.
3. لمنع الخروج من المنيو: **الإعدادات → إمكانية الوصول → الوصول الموجَّه (Guided Access)**.
4. اضبط **القفل التلقائي** على "أبداً" حتى تبقى الشاشة مضاءة.

## هيكل الملفات

```
index.html        شاشة المنيو
admin.html        لوحة التحكم
css/menu.css      تصميم المنيو
css/admin.css     تصميم لوحة التحكم
js/defaults.js    البيانات الأصلية (الأصناف والأسعار والإعلانات)
js/store.js       الحفظ المحلي والنسخ الاحتياطي
js/menu.js        منطق شاشة المنيو
js/admin.js       منطق لوحة التحكم
Assets/           صور المنيو والمنتجات
```

لتغيير البيانات الأصلية لكل الأجهزة، عدّل `js/defaults.js`. التعديلات المحلية المحفوظة على الجهاز تبقى لها الأولوية حتى يتم "استعادة الافتراضي".
